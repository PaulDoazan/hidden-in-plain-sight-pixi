# Handbook — Hidden in Plain Sight

Handbook pédagogique sur les WebSockets NestJS et l'architecture AWS du projet.

## Régénérer le HTML

```bash
pnpm build:handbook
```

Sortie : `docs/handbook-websockets/handbook.html`.

## Imprimer en PDF

1. `open docs/handbook-websockets/handbook.html` (ou double-clic depuis Finder)
2. Cmd+P
3. Destination : "Enregistrer en PDF"
4. Marges : par défaut
5. Cocher "Graphiques d'arrière-plan"
6. Enregistrer
